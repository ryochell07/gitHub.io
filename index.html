kaisetsu-auto

解説動画の制作・投稿支援ツール（個人用）

kaisetsu-auto は、運営者が自分の YouTube チャンネルに解説動画を投稿するために使う、個人用のツールです。運営者自身の Mac の上だけで動き、一般の方に向けたサービスではありません。

できること

  • 運営者が作った解説動画を、YouTube Data API を使って運営者自身のチャンネルに非公開でアップロードします。
  • 動画のサムネイル、タイトル、説明文を設定します。
  • 運営者が内容を確認して承認した動画だけを、公開または予約公開に切り替えます。

投稿は1日1本程度です。ほかの人のチャンネルや動画の情報を集めたり、操作したりすることはありません。

kaisetsu-auto

A personal tool for producing and uploading explainer videos

kaisetsu-auto is a personal, single-user tool that the channel owner uses to upload explainer videos to their own YouTube channel. It runs only on the owner's own Mac and is not offered to the public.

  • Uploads videos created by the owner to the owner's own channel as private, using the YouTube Data API.
  • Sets the thumbnail, title and description of those videos.
  • Changes a video to public (or scheduled) only after the owner has reviewed and approved it.

It uploads about one video per day and never accesses or modifies other users' channels or videos.
