プライバシーポリシー

kaisetsu-auto ／ 制定日：2026年10月30日

kaisetsu-auto（以下「本ツール」）は、運営者が自分の YouTube チャンネルに動画を投稿するために使う個人用ツールです。本ツールは YouTube API サービスを利用しています。本ツールを使うことで、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いは Google プライバシーポリシーをご覧ください。

1. 利用する情報

本ツールは、Google アカウントで許可を受けたうえで、YouTube API サービスを通じて次の情報を利用します。

  • 運営者のチャンネルの基本情報（チャンネル名・チャンネルID）
  • 本ツールがアップロードした動画の情報（動画ID、公開状態、処理状況）
  • 認証のためのアクセストークンとリフレッシュトークン

運営者以外の利用者の個人情報や、ほかのチャンネル・視聴者の情報は取得しません。

2. 利用の目的

動画のアップロード、サムネイル・タイトル・説明文の設定、公開状態の変更（運営者が承認した場合のみ）のためだけに利用します。

3. 保存と共有

  • 情報は運営者自身の Mac の中だけに保存し、外部のサーバーには送りません（Google の API を除く）。
  • 認証情報は、運営者だけが読めるファイルとして保存します。
  • 第三者への提供、販売、広告への利用はしません。
  • 本ツールは Cookie を使用せず、閲覧者の端末に情報を保存したり、端末から情報を読み取ったりしません。

4. 保存期間と削除

アップロード結果の記録は運用のために保存します。アクセストークンは、許可が取り消されるか本ツールの利用をやめた時点で削除します。許可は Google アカウントのセキュリティ設定（サードパーティ アクセス）からいつでも取り消せます。取り消すと、本ツールは YouTube にアクセスできなくなります。

5. 変更

このポリシーを変更する場合は、このページで公開します。

Privacy Policy

kaisetsu-auto / Effective: October 30, 2026

kaisetsu-auto ("the Tool") is a personal tool the channel owner uses to upload videos to their own YouTube channel. The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

1. Information accessed

With authorization through the owner's Google account, the Tool uses the following via YouTube API Services: the owner's channel basics (title, channel ID); information about videos uploaded by the Tool (video ID, privacy status, processing status); and OAuth access and refresh tokens. It does not collect personal information of any other user, channel or viewer.

2. Use

Solely to upload videos, set thumbnails, titles and descriptions, and change privacy status when the owner approves.

3. Storage and sharing

All data is stored only on the owner's own Mac and is not sent to any server other than Google's APIs. Credentials are stored in files readable only by the owner. Data is never sold, shared with third parties or used for advertising. The Tool does not use cookies and does not store or read information on any viewer's device.

4. Retention and deletion

Upload records are kept for operation. Tokens are deleted when authorization is revoked or the Tool is no longer used. Authorization can be revoked at any time from Google security settings (third-party access).

5. Changes

Any changes to this policy will be published on this page.
